Templed

Exploring the HackTheBox Templed challenge, with notes and screenshots from the solution.

m₀m0ss1·6 October 2020

Prerequisites

  • Kali Linux.
  • First, we are given a download link and a password for the ZIP file. After downloading and opening it, we find the following image.

The image filename gave me a starting point. After some research, I found that it depicts an ancient system of symbols.

Reversing “Numbers Of Monks”

Using those symbols, we decode the number represented by each one. The following image shows how this works.

Python to ASCII

Next, a very simple Python script converts the numbers into characters so that we can obtain the flag. Here is the code:

to_ascii = [ 72, 84, 66, 123, 77, 48, 78, 107, 115, 95, 107, 78, 51, 119, 33, 125 ]

for i in to_ascii:
    print(chr(i), end =" ")
